El programa muestra los datos del estudiante y dibuja el contorno de un cuadrado con asteriscos mediante una matriz de listas. La variable `lado` permite cambiar el número de filas y columnas; debe ser un entero mayor o igual que 2.

## Ejecución

Se requiere Python 3. No utiliza bibliotecas externas.

1. Descargar `actividad_python.py` y abrirlo en Visual Studio Code.
2. Seleccionar el intérprete con **Python: Select Interpreter**.
3. Pulsar **Run Python File**.

También se puede ejecutar desde una terminal situada en la carpeta del archivo:

```bash
python3 actividad_python.py
```

En Windows, si Python está disponible mediante el lanzador:

```powershell
py actividad_python.py
```
